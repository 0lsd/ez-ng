*ISSUE 9/14/2026 1.42*

-----------------------------------

**ISSUE**

'N1.' and 'M1.' have a thinner outlime than all of the other buttons.

**CAUSE**

'button_size' controled only width and height so border appearance is being left to Tkinter's defaults.

**FIX**

REPLACED:

button_size = {"width": 16, "height": 1}

TO:

button_size = {
    "width": 16,
    "height": 1,
    "relief": tk.RAISED,
    "borderwidth": 2,
    "highlightthickness": 0
}
